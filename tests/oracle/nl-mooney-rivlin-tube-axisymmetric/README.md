# Inflation of a stretched Mooney–Rivlin tube, axisymmetric

The tube of `nl-mooney-rivlin-tube` (A = 10, B = 20, one unit long; E = 3, ν = 0.4995,
C₀₁ = 0.2) as an axisymmetric model of 12 × 2 hybrid quad4 (one constant pressure each, the mean
dilatation with the hoop strain): the end y = 0 on a symmetry line, the end y = 1 stretched to
λ_z = 1.5 while the follower pressure p = 0.540850 inflates the bore. The closed form puts the
bore at a = 15 and the outer wall at b = 20.615528 (see `nl-mooney-rivlin-tube`); this case checks
the nearly incompressible 2D hybrid elements at large strain against it.
