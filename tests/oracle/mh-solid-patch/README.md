# MacNeal–Harder patch test for solids (hex8 with incompatible modes)

Our model of the published problem: a unit cube cut into seven hexahedra around an irregular inner
hexahedron (inner node coordinates from Fig. 3), E = 10⁶, ν = 0.25, with the linear displacement
field of Table 2(c) prescribed at the eight corners. The published solution is the uniform strain
10⁻³ with σ_x = σ_y = σ_z = 2000 and τ = 400.
