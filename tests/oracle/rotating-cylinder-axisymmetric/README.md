# Long rotating solid cylinder, axisymmetric

A solid cylinder of radius 1 (E = 1000, ν = 0.3, ρ = 10⁻³) spinning at 30 rad/s about its axis y,
as an axisymmetric slice 0 ≤ y ≤ 0.2 held axially on both faces (ε_z = 0): one quad8 patch of
16 × 2. σ_r = (3 − 2ν)/(8(1 − ν)) ρω²(b² − r²), σ_θ = ρω²/(8(1 − ν)) ((3 − 2ν)b² − (1 + 2ν)r²).
