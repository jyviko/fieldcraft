# MacNeal–Harder thick-walled cylinder, nearly incompressible (hex8 with incompatible modes)

Our model of the published problem: inner radius 3, outer 9, thickness 1, E = 1000, plane strain,
unit internal pressure, ν = 0.49, 0.499 and 0.4999 (three separate bodies in one model, solved
together). The radial element boundaries are those of Fig. 10 (3.0, 3.5, 4.2, 5.2, 6.75, 9.0);
we model a quarter with symmetry planes (nine 10° elements around) instead of one 10° slice,
which needs no skew support and is the same axisymmetric problem.
