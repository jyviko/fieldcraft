# Rigid rotation: objectivity

The distorted 3 × 3 × 3 hex8 cube of nl-patch-hex8 (neo-Hookean, E = 1000, ν = 0.3) with every
boundary node prescribed the motion of a 90° rotation about the axis (1, 1, 1)/√3, applied in
one ramp (the intermediate states are not rigid; the end state is). The inner nodes must follow
the rotation and the stress must vanish.
