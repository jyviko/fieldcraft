# Large-deflection cantilever (elastica)

A cantilever L = 10, b = 1, h = 0.5 (L/h = 20) of 40 × 1 × 2 hex20 elements, clamped at x = 0,
E = 10⁴, ν = 0 (an elastic material in a nonlinear step: St Venant–Kirchhoff, exact for large
rotations with these small strains), under a dead vertical tip force P spread over the end face.
Four steps at P L²/(E I) = 1, 2, 5 and 10 (rotations of the tip 0.46 to 1.43 rad). The tip's
neutral-axis node (10, 0, 0.25) is compared with the elastica (Bisshopp–Drucker), whose values
were computed by shooting and agree with Mattiasson's table.
