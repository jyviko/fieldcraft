# Elastic bar striking a rigid wall (explicit)

A bar 10 × 0.1 × 0.1 of 200 one-point hex8 elements (E = 10⁴, ρ = 1, ν = 0, c = 100) moving at
v₀ = 0.1 towards a frictionless rigid wall at x = 0 (its end face is the contact set); linear bulk
viscosity off. Solved to t = 0.3: in contact from 0 to 2L/c = 0.2, then free at +v₀.
