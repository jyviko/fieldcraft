# NAFEMS LE10 thick plate under pressure (hex20)

Our model of the published problem: the elliptic plate of LE1 (inner (x/2)² + y² = 1, outer
(x/3.25)² + (y/2.75)² = 1), 0.6 thick, E = 210 GPa, ν = 0.3, 1 MPa pressure on the upper face;
u_y = 0 on y = 0, u_x = 0 on x = 0, u_x = u_y = 0 on the outer curved face, u_z = 0 on the line
where the outer face meets the mid-surface. Two layers of hex20 blocks (8 × 16 × 3 each).
