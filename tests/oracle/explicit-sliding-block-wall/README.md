# Block sliding to a stop on a rigid wall (explicit, Coulomb friction)

A block 1 × 1 × 0.5 of 4 × 4 × 2 one-point hex8 elements (E = 10⁵, ν = 0.3, ρ = 1, so m = 0.5)
rests on a rigid wall at z = 0 (its bottom nodes) with Coulomb friction μ = 0.3, under gravity
g = 10, and is launched along x at v₀ = 3. Theory for a rigid block: deceleration μg, stop after
v₀/(μg) = 1 at v₀²/(2μg) = 1.5, the kinetic energy ½mv₀² = 2.25 all dissipated by friction.
Solved to t = 1.3.
