# Constrained Delaunay mesh of a cylinder: volume within the chordal bound, valid elements

A cylinder R = 10, H = 20 built with SolidCraft from `design.json`, tessellated within 0.05 and
tetrahedralized by `mesh.tet.generate`. The mesh fills the inscribed polyhedron, whose volume lies
between (1 − 2s/R)πR²H and πR²H.
